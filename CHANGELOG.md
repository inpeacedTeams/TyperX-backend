# Changelog

## 1.0.0 - 2026-08-17

- Built the product on Python 3.12.
- Added a layered domain, service, platform, and persistence architecture.
- Replaced uniform delays with burst-based, lognormal human rhythm.
- Added conservative Russian semantic message splitting and stable preview plans.
- Added Win32 Unicode input, including surrogate-pair support for emoji.
- Added focus locking, global emergency stop and local-only persistence.
- Added template search, safe built-in templates, custom templates and atomic autosave.
- Added Windows CI, automated tests, and tagged releases.
